# Auto Clicker V1

یک Auto Clicker برای Windows با C# / WPF و .NET Framework 4.8.

## قابلیت‌ها

- افزودن نقطه با کلیک روی هر جای صفحه
- ذخیره مختصات X/Y
- ثبت رنگ مستقل برای هر نقطه
- امکان فعال یا غیرفعال کردن بررسی رنگ برای هر نقطه
- امکان داشتن رنگ متفاوت برای هر نقطه
- اجرای چند نقطه به صورت ترتیبی
- تأخیر مستقل برای هر فاصله بین دو کلیک
- امکان تعیین فاصله بین نقطه آخر و نقطه اول
- پشتیبانی از زمان‌های اعشاری مانند:
  - 0.1 ثانیه
  - 0.5 ثانیه
  - 1.25 ثانیه
  - 2.5 ثانیه
  - 10 ثانیه
- تعداد تکرار قابل تنظیم
- تکرار نامحدود
- بررسی رنگ قبل از کلیک
- توقف اجرای کلیک‌ها
- خروجی 32 بیتی و 64 بیتی
- سازگاری با Windows 8.1 و نسخه‌های جدیدتر Windows
- بدون OCR و بدون تشخیص متن
