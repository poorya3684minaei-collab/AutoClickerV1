# Auto Clicker V1

نسخه اول یک Auto Clicker برای Windows با C# / WPF و .NET 10.

## قابلیت‌ها

- افزودن نقطه با کلیک روی هر جای صفحه
- ذخیره X/Y
- ثبت رنگ همان نقطه
- اجرای چند نقطه به صورت ترتیبی
- تاخیر مستقل برای هر نقطه
- تعداد تکرار
- تکرار نامحدود
- بررسی رنگ قبل از کلیک
- اگر رنگ مطابق نباشد، کلیک انجام نمی‌شود
- Stop برای توقف اجرا
- خروجی x86 و x64 از طریق GitHub Actions

## پیش‌نیاز توسعه

Visual Studio 2026 با workload مربوط به Desktop development with .NET و .NET 10 SDK.

## اجرای محلی

```powershell
dotnet restore
dotnet build -c Release
dotnet run -c Release
```

## انتشار x64

```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

## انتشار x86

```powershell
dotnet publish -c Release -r win-x86 --self-contained true /p:PublishSingleFile=true
```

## روش استفاده

1. روی «افزودن نقطه» بزن.
2. روی محل موردنظر کلیک کن.
3. نقاط بعدی را به همین روش اضافه کن.
4. یک نقطه را انتخاب کن و تاخیر آن را تنظیم کن.
5. برای شرط رنگ، «فعال کردن بررسی رنگ» را بزن.
6. تعداد تکرار را تعیین کن یا «تکرار نامحدود» را فعال کن.
7. «شروع» را بزن.

### نکته درباره بررسی رنگ

رنگ هنگام ساخت/ویرایش نقطه ذخیره می‌شود.

مثلاً اگر رنگ ذخیره‌شده:

`#FFFFFF`

باشد و Tolerance برابر 10 باشد، رنگ فعلی باید در محدوده اختلاف حداکثر 10 برای کانال‌های R/G/B قرار بگیرد؛ در غیر این صورت کلیک رد می‌شود.
